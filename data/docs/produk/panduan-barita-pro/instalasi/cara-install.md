# Cara Install Barita Pro

Panduan ini menjelaskan cara memasang tema Barita Pro di situs WordPress.
Ikuti langkah-langkahnya berurutan — tidak ada langkah yang boleh dilewati.

## Yang dibutuhkan

- Situs WordPress yang sudah berjalan
- File ZIP tema Barita Pro
- Akses ke menu **Tampilan > Tema** di wp-admin

## Langkah instalasi

1. Masuk ke wp-admin situs Anda.
2. Buka menu **Tampilan > Tema**, lalu klik **Tambah Baru**.
3. Klik **Unggah Tema**, pilih file ZIP Barita Pro, lalu klik **Install Sekarang**.
4. Setelah instalasi selesai, klik **Aktifkan**.

## Setelah tema aktif

- Buka **Tampilan > Sesuaikan** untuk mengatur identitas situs, menu, dan widget.
- Impor konten demo bila tersedia, lalu ganti dengan konten Anda sendiri.
- Periksa halaman depan di perangkat ponsel dan desktop.

## Bila instalasi gagal

- Pastikan file ZIP berisi satu folder tema di tingkat teratas.
- Pastikan ukuran file tidak melebihi batas unggah hosting Anda.
- Bila masih gagal, unggah folder tema lewat SFTP ke `wp-content/themes/`.
